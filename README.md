# BIDHUB (Đồ án cuối kì Online Auction - 23KTPM3)

![bidhub's website illustration](illustration.png)

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** Supabase (PostgreSQL)
- **Frontend:** Handlebars (SSR), Tailwind CSS
- **Auth:** Passport.js, bcrypt
- **Session:** express-session, connect-session-knex
- **Realtime:** fetch API (AJAX)
- **Other:** Preline UI, Nodemailer, reCAPTCHA v2

## Hướng dẫn cài đặt & chạy web

### 1. Clone repo
```bash
git clone https://github.com/yourusername/online-auction.git
cd online-auction
```

### 2. Cài đặt thư viện
```bash
npm install
```

### 3. Tạo file môi trường
Tải file `.env` tại [Google Drive - .env](https://drive.google.com/drive/folder/test-env-link)

### 4. Chạy web
```bash
npm run dev
```
Truy cập: [http://localhost:3000](http://localhost:3000)
